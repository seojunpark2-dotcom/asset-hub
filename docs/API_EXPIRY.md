# API 만료일과 휴대폰 알림 · 앱 1.1.0

## 시작하기
1. 기존 앱을 삭제하지 않고 새 APK를 업데이트 설치합니다.
2. 로그인한 뒤 설정 → 공공데이터 API 이용기간을 엽니다.
3. 만료예정일의 기본값은 사용자가 확인한 2028-10-11입니다. 포털 표시 날짜가 다르면 수정하세요.
4. 만료 전 알림 → 켜기를 선택하고 만료일·알림 저장을 누릅니다.
5. Android의 알림 권한 요청을 허용합니다. 권한을 거부했다면 휴대폰 알림 설정 열기 → 앱 알림 허용 후 앱으로 돌아옵니다.
6. 테스트 알림 보내기를 누르면 약 5초 뒤 로컬 알림이 표시됩니다. 테스트 결과는 실기기에서 직접 확인해야 합니다.

## 표시와 알림
- 설정에 만료예정일과 남은 일수(한국 날짜 기준)가 표시됩니다.
- 만료 30일 이내 및 만료 후에는 홈에 경고가 표시됩니다.
- 만료 30일 전·7일 전·1일 전·당일 오전 9시(한국시간)에 로컬 알림을 예약합니다. 지나간 예약 시점은 제외됩니다.
- 2028-10-11 기준 예약일: 2028-09-11, 2028-10-04, 2028-10-10, 2028-10-11.
- 알림을 누르면 설정 화면으로 이동합니다. 앱이 닫혀 있어도 OS 예약으로 알림을 전달하며 앱 실행 시 예약을 점검합니다.
- Android 절전·제조사 정책·알림 채널 차단·강제 종료 등으로 알림이 지연되거나 표시되지 않을 수 있습니다. 정확한 시각을 강제하는 특별 권한은 요구하지 않습니다.

## 연장 후
공공데이터포털에서 이용기간을 연장한 뒤 새 만료일을 설정에 입력하고 저장하세요. 기존 알림을 정리하고 새 날짜에 예약합니다. 연장이 반드시 같은 날짜의 2년 후라는 가정으로 자동 계산하지 않습니다.

## 데이터와 범위
- 만료일은 이용자가 확인한 날짜를 저장하는 기능입니다. API 키 값이나 실제 공급자 만료 상태를 읽지 않으며 자동 연장도 하지 않습니다.
- 만료일·알림 선호는 기존 portfolio_profiles.settings에 저장되며 사용자 RLS가 적용됩니다. 별도 DB 스키마 변경은 필요하지 않습니다.
- 알림 권한·예약은 각 휴대폰별로 설정됩니다. 새 기기나 재설치 후 앱을 열고 알림 권한과 예약 상태를 확인하세요.
- 로그아웃 또는 계정 변경 시 이전 계정의 예정 알림을 취소합니다. 앱 삭제 시 로컬 알림도 삭제됩니다.
- Finnhub에는 확인된 만료일이 없으므로 이 기능의 대상은 공공데이터포털 국내 ETF/주식 서비스 이용기간입니다.
- API 키가 바뀐 경우 Supabase Secrets에 새 키를 등록하는 절차는 별도로 필요합니다.
