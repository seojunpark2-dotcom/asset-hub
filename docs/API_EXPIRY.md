# api 브랜치 1.4.0 변경

이 버전은 공공데이터 만료일 입력·알림을 사용하지 않습니다. 로그인 시 기존 기기의 만료 알림을 취소합니다. 설정에 한국투자 키 연결 상태와 접근 토큰 만료시간을 보여주며 서버가 토큰을 자동 관리합니다. [자동화 범위와 최초 설정](KIS_API.md)을 확인하세요. 아래는 master / 1.3.3의 기존 동작 기록입니다.

# API 만료일과 휴대폰 알림 · 앱 1.3.3

## 사용 순서
1. 기존 앱을 삭제하지 않고 GitHub에서 받은 APK를 실행해 업데이트합니다.
2. 로그인 → 설정 → 공공데이터 API 이용기간을 엽니다.
3. 만료예정일 선택 버튼을 누르고 달력에서 날짜를 고릅니다. 기본값은 2028-10-11입니다.
4. 날짜를 선택하면 자동 저장됩니다. 만료 전 알림 켜기·끄기도 자동 저장됩니다. 알림을 켤 때 Android 알림 권한 요청을 허용합니다.
5. 권한이나 소리를 바꾸려면 시세 갱신 간격 아래 별도 알림 설정 카드의 휴대폰 알림 설정 열기를 누릅니다.

## 한 번의 알림과 다음 날짜
- 만료 7일 전 한국시간 오전 9시를 기준으로 알림 한 개만 예약합니다. 이전 버전의 30·1일 전 및 당일 알림과 테스트 알림은 정리합니다.
- 알림이 실제로 표시된 날에 Android 수신기가 앱의 다음 만료예정일을 그날부터 2년 뒤로 저장합니다. 앱이 닫혀 있어도 처리하며, 다음 앱 실행에서 서버에 동기화합니다. 연결 실패 시 휴대폰 값을 보관하고 다시 시도합니다.
- 예: 2028-10-11 만료 → 2028-10-04 알림 → 다음 만료예정일 2030-10-04. OS 사정으로 10월 5일에 표시됐다면 2030-10-05입니다. 2월 29일의 2년 뒤는 2월 28일로 설정합니다.
- 알림 차단 또는 전달 실패 시 날짜를 자동 변경하지 않습니다. 새로 선택한 날짜의 알림 시간이 이미 지났다면 소급 알림을 보내지 않습니다.
- 다음 만료예정일에도 7일 전 알림 한 개를 예약합니다. 수동 날짜 변경은 이전 자동 변경 기록을 초기화합니다.
- 재부팅 및 APK 업데이트 시 향후 예약을 복구합니다. 강제 종료 후에는 앱을 다시 열어야 합니다. 기기가 꺼진 동안 지나간 알림은 소급하지 않습니다.
- 테스트 알림 버튼은 제거했습니다. 알림을 누르면 설정 화면으로 이동합니다.

## 실제 API 이용기간
자동 변경은 앱의 날짜만 바꿉니다. **공공데이터포털의 실제 이용기간은 직접 연장해야 합니다.** 포털에서 표시하는 만료일이 앱의 계산값과 다르면 달력에서 정확한 날짜를 선택해 저장하세요. API 키를 교체한 경우 Supabase Secrets 설정도 별도로 변경해야 합니다.

만료일은 사용자별 설정에 저장합니다. API 키 값이나 공급자의 실제 만료 상태를 조회하지 않습니다. 알림 권한과 예약은 각 기기에서 관리하며, 로그아웃 시 해당 기기의 예약을 취소합니다.

알림은 Android의 절전 및 제조사 정책으로 지연되거나 표시되지 않을 수 있습니다. 정확한 시간 알림을 위한 특별 권한은 요청하지 않습니다. [Android 알림 예약 동작](https://developer.android.com/develop/background-work/services/alarms)을 참고하세요. 실제 휴대폰에서의 알림 수신은 별도 확인이 필요합니다.
