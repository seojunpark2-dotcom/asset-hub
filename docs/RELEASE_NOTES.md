Wi-Fi 이름과 공인 IP 조합을 최대 10곳까지 등록할 수 있습니다. 설정 → 계좌 자동 연동 → 현재 Wi-Fi 추가를 누르고 각 장소에서 등록하세요. 목록에서 별칭·Wi-Fi 이름·IP를 수정하거나 항목을 삭제할 수 있습니다. 각 공인 IP는 조회할 기관의 API 허용 목록에도 등록해야 합니다.

등록된 어느 장소에서든 계좌를 조회하지만 한국 날짜 기준 기관별·기기별 정상 잔고는 하루 한 번만 가져옵니다. 장소 이동이나 Wi-Fi 목록 편집으로 조회 횟수가 초기화되지 않습니다. 이름과 IP는 한 항목 안에서 모두 일치해야 하며 중복 조합·잘못된 IP·사설 IP 입력은 거부합니다. 기존 집 Wi-Fi는 자동 이전하고 API 키·조회 기록·위젯 기능은 유지합니다. 모든 Wi-Fi를 삭제하면 계좌 자동 조회를 멈춥니다.

호환되는 복수 Wi-Fi 기능 추가로 1.12.0 / versionCode 22를 적용했습니다. 기존 앱을 삭제하지 않고 업데이트하세요. 실제 장소별 Wi-Fi·기관 키·백그라운드 동작은 휴대폰에서 확인해야 합니다. Android 절전·네트워크 상태로 실행이 늦어질 수 있습니다.
