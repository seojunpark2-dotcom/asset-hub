계좌 동기화 후 최신 보유수량·매입원금과 공개 시세로 위젯의 종목별 수익률·총평가금액·전체 평가손익 및 수익률을 갱신합니다. 위젯 갱신에 실패하면 대기 상태를 기기에 기록하고 계좌 재조회 없이 재시도합니다. 앱·자정 위젯·주기 작업이 같은 일일 계좌 조회 기록을 사용합니다.

설정 맨 위에 계좌 조회 현황을 추가했습니다. 기관별 최근 계좌 조회 실행 시각, 동기화 성공 시각, 조회에 사용한 공인 IP를 한국 시간으로 표시합니다. 등록한 집 Wi-Fi·기관 허용 IP, 최근 확인한 Wi-Fi 공인 IP와 확인 시각, 위젯 반영 완료·대기 상태도 확인할 수 있습니다. 현재 Wi-Fi IP 확인 버튼은 계좌를 조회하지 않습니다.

호환되는 조회 현황 기능 추가에 따라 1.11.0 / versionCode 21을 적용했습니다. 기존 앱을 삭제하지 않고 업데이트하세요. 집 Wi-Fi·키 설정은 유지됩니다. 키/위치 권한/공인 IP 등록이 되어 있어야 계좌 조회가 가능합니다. 절전·네트워크 제한에 따라 자동 작업이 지연될 수 있습니다. 실제 계좌와 휴대폰 동작은 설정 후 확인이 필요합니다.
