버전 규칙을 변경 종류에 따른 major.minor.patch 방식으로 수정했습니다. 기존 기능 추가 이력을 기준으로 앱 버전을 1.2.1로 복원했습니다. 앞으로 호환되지 않는 큰 변경은 앞 숫자, 호환되는 기능 추가는 중간 숫자, 오류 수정·기능 추가 없는 정리는 마지막 숫자를 올립니다. 중간 숫자를 올리면 마지막은 0, 앞 숫자를 올리면 나머지는 0으로 초기화합니다.

Android versionCode는 5에서 6으로 올렸고 기존 패키지와 서명을 유지합니다. 기존 앱을 삭제하지 않고 APK를 실행해 업데이트하세요.

달력에서 만료예정일 선택, 7일 전 단일 알림, 알림일 기준 2년 뒤 날짜 변경 기능을 포함합니다. 공공데이터포털의 실제 이용기간은 별도로 연장해야 합니다.

GitHub Actions에서 생성한 ARM 32/64비트 Android APK와 SHA256 확인 파일을 함께 제공합니다. 기존 1.0.3과 과거 APK는 보존합니다. 버전 이력과 새 규칙은 docs/VERSIONS.md에 기록했습니다.
