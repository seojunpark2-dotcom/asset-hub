집 Wi-Fi에서 휴대폰이 직접 키움·업비트 잔고를 조회하도록 변경했습니다. 별도 중계 서버 없이 집 Wi-Fi 이름과 공인 IPv4를 등록하고, 기관 API 허용 IP를 맞춘 뒤 앱에 API 키를 입력합니다. 키는 Android Keystore로 암호화해 이 휴대폰에만 보관합니다.

한국 날짜 기준 기관별 정상 잔고를 하루 한 번 가져옵니다. WorkManager가 15분 주기의 작업 기회에 집 Wi-Fi와 공인 IP를 확인하며 Android 절전 상태에서는 지연될 수 있습니다. 앱 새로고침·상태 확인·위젯 작업은 동일한 일일 기록을 사용합니다. 조회 실패는 30분 이상 뒤 재시도하고, 받은 잔고의 저장만 실패하면 보관된 스냅샷을 재전송합니다. 집에 연결되지 않은 날은 기존 잔고를 유지합니다. 집에서 동기화에 성공하면 위젯도 반영하며 공개 시세 갱신은 유지합니다.

설정 → 계좌 자동 연동에서 집 Wi-Fi 등록 → 정확한 위치·항상 허용 권한 → 표시된 공인 IP를 기관에 등록 → API 키 입력 순서로 설정하세요. 집 공인 IP가 바뀌거나 API 키가 만료되면 직접 수정해야 합니다. 별도 서버 비용은 필요하지 않으며 기존 Supabase는 로그인·자산 저장용으로 유지합니다.

새 기능 추가에 따라 1.10.0 / versionCode 20을 적용했습니다. 기존 앱을 삭제하지 않고 업데이트하세요. GitHub 파일명 제약으로 직접 APK는 asset-hub-1.10.0.apk이며 ZIP 안에 통합 자산관리 - 1.10.0.apk를 보존합니다. 실제 키·휴대폰이 준비되지 않아 실계좌·밤사이 수신·배터리 검증은 설정 후 필요합니다.
