버전 표기를 APK 배포 횟수 기준으로 정리했습니다. 이전 1.0.0, 1.1.0, 1.2.0은 각각 새 순번 1.0.0, 1.0.1, 1.0.2에 대응하며, 이번 APK는 1.0.3입니다. 앞으로는 1.0.4, 1.0.5처럼 마지막 숫자만 증가합니다.

Android versionCode는 4에서 5로 올렸고 기존 패키지와 서명을 유지합니다. 기존 앱을 삭제하지 않고 APK를 실행해 업데이트하세요.

달력에서 만료예정일 선택, 7일 전 단일 알림, 알림일 기준 2년 뒤 날짜 변경 기능을 포함합니다. 공공데이터포털의 실제 이용기간은 별도로 연장해야 합니다.

GitHub Actions에서 생성한 ARM 32/64비트 Android APK와 SHA256 확인 파일을 함께 제공합니다. 과거 APK 파일은 당시 실제 버전 표기를 유지하며 docs/VERSIONS.md에 대응표를 기록했습니다.
