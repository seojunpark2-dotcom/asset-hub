키움증권·업비트 계좌 자동 연동 기능을 추가했습니다. 설정 → 계좌 자동 연동에서 실제 잔고를 가져오면 종목·보유수량·매입원금과 신규 매수·전량 매도가 반영됩니다. 첫 연결 시 해당 기관의 수동 자산을 계좌 잔고로 교체한다는 동의를 받으며, 연결 해제 시 마지막 잔고를 수동 자산으로 유지합니다.

자동 연동에는 본인 소유 고정 IP 서버와 기관별 API 키 설정이 필요합니다. 현재 서버·개인 키는 준비되지 않아 실제 계좌 연결은 미완료이며 설정 전에는 '연결 준비 필요'로 표시합니다. server/ 설치 구성과 docs/ACCOUNT_CONNECTIONS.md의 상세 안내를 제공합니다. 유료 서버는 생성하지 않았습니다.

지원 범위는 키움 국내 현금 주식·ETF와 업비트 KRW 기준 코인입니다. 예수금·신용·키움 해외주식·미래에셋은 이번 자동 연동에 포함하지 않습니다. 주식·ETF Yahoo 시세는 유지하며 별도 시세 키는 필요하지 않습니다. 계좌 연동 키는 서버 환경변수에 저장하고 APK에 넣지 않습니다.
