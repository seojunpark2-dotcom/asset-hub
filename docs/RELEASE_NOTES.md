보유자산 홈 화면 위젯을 추가했습니다. 총평가금액, 전체 평가손익·수익률, 종목명·금융기관·종목 수익률을 표시하며 원금·종목별 평가금액·손익 금액은 표시하지 않습니다. 목록 스크롤과 크기 조절을 지원합니다. 설정 → 보유자산 위젯에서 홈 화면 추가를 요청할 수 있습니다.

앱에서 갱신된 데이터를 표시하며 위젯을 누르면 앱을 열어 갱신합니다. 앱이 닫힌 동안 별도 실시간 서버 조회는 수행하지 않습니다. 로그아웃·계정 변경 시 이전 데이터는 지우며 시세 누락을 0으로 표시하지 않습니다. 사용 안내: docs/WIDGET.md.

홈 화면의 금융기관별 자산을 평가금액 내림차순으로 정렬했습니다. 계산 불가 기관은 마지막에 표시합니다.
