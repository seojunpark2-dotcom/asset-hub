# 위젯 하루 한 번 자동 갱신 (1.8.0)

## 1.11.0 변경

계좌 반영 성공 시 위젯 갱신 대기와 자산 변경 식별자를 기록합니다. 앱 조회·주기 계좌 작업·자정 위젯에서 최신 서버 보유자산과 공개 시세로 위젯을 재계산하고, 정상 반영 후에만 대기를 해제합니다. 네트워크·시세 오류·동시 자산 변경으로 반영이 실패하면 다음 작업에서 계좌 재조회 없이 위젯만 재시도합니다. 설정 최상단에 위젯 반영 시각/대기 상태와 계좌 실행·성공 시각·조회 IP를 표시합니다.

## 1.10.0 변경

계좌 조회는 집 Wi-Fi에서 휴대폰 직접 조회로 변경합니다. 한국 날짜별 기관별 하루 한 번 정상 잔고를 수신하며 자정 위젯 작업과 앱 새로고침도 동일한 기기 내 기록을 사용합니다. 집에서 계좌 동기화에 성공하면 위젯도 갱신합니다. 계좌 작업은 위젯을 삭제해도 유지하며 로그아웃·연결 해제로 중단합니다. 아래 1.9 서버 동기화 내용은 과거 버전의 동작입니다. [설정과 제한](ACCOUNT_CONNECTIONS.md).

## 1.9.0 변경 (과거)

계좌 연동용 기기 등록을 마치면 자정 작업이 먼저 서버에서 최신 보유자산을 가져옵니다. 연결한 키움·업비트 잔고를 동기화한 뒤 시세를 조회하므로 매수·매도와 다른 기기에서 수정한 서버 자산도 다음 백그라운드 갱신에 반영됩니다. 아래의 '앱에서 마지막 동기화한 보유자산' 설명은 기기 등록 전과 1.8.0 동작입니다. 서버·API 키·허용 IP 설정이 필요한 계좌 연동의 범위와 기기 토큰의 보관·만료는 [계좌 연결 안내](ACCOUNT_CONNECTIONS.md)를 따릅니다.

## 1.8.0 동작

- 한국 시간(Asia/Seoul) 매일 자정 00:00 이후 실행하도록 Android WorkManager에 예약한다. 휴대폰 시간대와 무관하게 한국 시간을 사용한다.
- 달력의 다음 자정으로 매번 다시 예약한다. 같은 날짜는 unique work로 중복 예약하지 않으며 성공한 한국 날짜에는 재조회하지 않는다. 정각 실행·완료를 보장하지 않는다. 절전, 앱 제한, 네트워크 상태에 따라 늦어질 수 있다.
- 앱을 열지 않아도 네이티브 Worker가 국내·미국 주식/ETF는 Yahoo, 코인은 Upbit, 환율은 Frankfurter를 직접 조회한다. 외부 시세 API 키나 증권사 계정, 새로운 서버 함수는 필요 없다.
- BigDecimal(40자리 정밀도)로 평가금액과 원화 투자원금 기준 손익·수익률을 계산한다. 자산 목록은 평가금액 내림차순이고 기존 위젯 표시·색상 규칙을 유지한다.
- 인터넷 연결이 필요하다. 조회 실패 시 마지막 실제 가격을 오래된 값으로 유지하며, 가격이 없으면 미확인(—)으로 표시한다. 조회 실패는 최대 2회 재시도(30분, 60분 기준; 시스템 지연 가능)한 후 다음 날 예약으로 넘어간다. 성공한 날짜는 재조회하지 않는다.
- 앱에서 마지막으로 동기화한 보유수량·원화 매입원금·색상·시세를 앱 전용 noBackupFilesDir에 저장한다. 암호나 인증 토큰은 Worker에 전달하지 않는다. 다른 기기에서 수정한 보유자산은 이 휴대폰 앱을 열어 동기화해야 반영된다.
- 위젯이 설치되어 있고 로그인한 계정의 입력 자료가 있을 때만 예약한다. 로그아웃·계정 변경 시 저장 자료를 지우고 작업을 취소한다. 위젯을 모두 삭제해도 작업을 취소한다. 실행 도중 계정·보유자산이 바뀌면 이전 결과를 반영하지 않는다.
- WorkManager가 재부팅 뒤 예약을 복구한다. 설정에서 앱을 **강제 종료**하거나 백그라운드 실행을 차단하면 갱신이 중단될 수 있다. 강제 종료 후에는 앱을 다시 열어야 한다. 최근 앱 목록에서 닫는 것과 설정의 강제 종료는 다르다.
- 업데이트 설치 후 로그인 상태로 앱을 한 번 열어 기존 보유자산 입력 자료를 저장해야 자동 갱신을 시작할 수 있다. 위젯을 다시 만들 필요는 없다.
- 소리·푸시 알림·상시 실행 서비스·정확한 알람 권한은 추가하지 않는다. 배터리 소모량과 실제 기기의 자정 갱신은 실기기에서 별도 확인한다.

앱 화면이 열려 있을 때의 기존 1/5/15분 갱신은 유지한다. 하루 한 번은 위젯 백그라운드 조회 주기이며, 앱을 열면 위젯에도 더 최신 결과가 반영될 수 있다. Yahoo 가용성 및 지연 가능성은 기존과 동일하다.
