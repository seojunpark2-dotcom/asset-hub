# 하루 한 번 Wi-Fi 통합 갱신 · 1.16.0

1.16.0부터 계좌 투자원금 1원 미만 자산을 삭제한다. 앱을 열어 정리된 자산 목록을 읽으면 위젯의 삭제된 행도 즉시 제거하고 저장된 시세로 합계를 재계산한다. 이 삭제 정리는 일일 계좌·시세 조회를 추가 실행하거나 당일 완료 기록을 초기화하지 않는다. 일반적인 자산 추가·수량·시세 변경에는 아래 하루 갱신 정책을 유지한다.

사용자 요청(2026-10-18)에 따라 계좌 조회·위젯 시세 조회·위젯 평가금액/손익/수익률 반영을 한 작업으로 통합했다. 이전의 자정 위젯 작업과 앱 화면 갱신에 따른 위젯 덮어쓰기는 중단한다.

- 한국 날짜 기준 기기당 하루 한 번 정상 완료한다. 등록된 SSID와 공인 IPv4가 같은 항목에서 모두 일치하는 Wi-Fi에서 실행한다. 기관 허용 IP 등록은 유지한다.
- Android WorkManager의 약 15분 간격 실행 기회에 조건을 확인한다. Wi-Fi 연결 직후나 특정 시각을 보장하지 않는다. 앱을 열지 않아도 동작하며 절전/강제 중지/네트워크/위치 권한에 따라 지연될 수 있다.
- 순서: Wi-Fi/IP 확인 → Supabase 최신 키 → 연결 기관의 미조회 잔고 → 자산 업로드 → 전체 보유자산 최신 시세/환율 → 위젯 평가금액·손익·수익률 한 번에 저장.
- 기관별 오늘 정상 조회한 잔고는 재조회하지 않는다. 일부 기관 실패 시 성공한 기관 기록과 업로드 대기를 보존하고 실패 기관만 30분 이상 후 재시도한다. 정상 잔고 업로드 대기는 키/기관을 재조회하지 않는다.
- 모든 연결 기관의 당일 잔고 업로드와 전체 시세 조회가 성공해야 위젯을 반영한다. 일부 실패나 Wi-Fi 변경 시 이전 위젯 화면을 유지하고 다음 조건 충족 기회에 재시도한다. 시세 실패는 15분 이상 뒤 재시도하며 계좌를 다시 읽지 않는다.
- 실제 시세 HTTP도 확인한 Wi-Fi Network에 고정한다. 갱신 도중 Wi-Fi를 잃으면 모바일 데이터로 우회하지 않으며, 반영 전에도 같은 Wi-Fi Network인지 확인한다.
- 완료 위젯과 dailyWifiDay를 하나의 AtomicFile 쓰기로 저장한다. 당일 완료 후에는 앱 진입·재연결·버튼·기관 추가로도 다시 갱신하지 않는다. 새 기관/수동 자산 변경은 다음 날 통합 갱신부터 위젯에 반영한다. 로그아웃은 개인정보 보호를 위해 즉시 위젯을 비운다.
- 자정 예약은 기존 portfolio-widget-daily 태그 전체를 취소한다. 이전 WidgetRefreshWorker 클래스는 남겨 예약 복구 시 네트워크/쓰기를 하지 않고 종료한다. 유일한 주기 작업은 기존 portfolio-home-account-daily이다.
- 앱 화면은 기존 1/5/15분 시세 갱신을 유지한다. 기본 1분, Yahoo 주식/ETF 응답 5분 캐시, 환율은 일별 기준이다. 이 갱신은 위젯 숫자를 바꾸지 않는다. foreground 입력의 시세만 바뀌어도 위젯 작업 revision을 무효화하지 않는다.
- 기존 로그인·암호화 키·Wi-Fi 목록·기관별 하루 기록·전송 대기·마지막 위젯 화면은 유지한다. 모든 Wi-Fi 삭제/로그아웃 시 통합 작업을 중단한다. 위젯 전체 삭제만으로 계좌 주기 작업은 중단하지 않으며, 저장된 일일 화면은 다시 위젯을 추가할 때 사용한다.

실제 기관 키·개인 계좌와 휴대폰의 Wi-Fi/절전 상태 실행은 실기기 확인이 필요하다.
