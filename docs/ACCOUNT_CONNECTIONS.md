# 등록 Wi-Fi에서 하루 한 번 계좌 자동 조회 (1.12.0)

## 여러 Wi-Fi 등록 (1.12.0)

- 설정 → 계좌 자동 연동 → **현재 Wi-Fi 추가**로 연결한 장소의 SSID와 공인 IPv4를 추가합니다. 최대 10개 조합을 지원합니다. 각 공인 IP는 이용할 기관의 API 허용 목록에도 별도로 등록합니다. 앱 목록 삭제는 기관의 허용 IP를 삭제하지 않습니다.
- 목록의 수정에서 별칭(집/회사 등), SSID, 공인 IP를 수정할 수 있고 항목별 삭제도 가능합니다. 이름과 IP가 모두 같은 중복은 추가하지 않으며 수정으로 중복을 만들 수 없습니다. 같은 SSID에 서로 다른 IP 또는 같은 IP에 서로 다른 SSID는 등록할 수 있습니다.
- 기관 조회는 **같은 항목의 SSID와 공인 IP가 모두 일치**할 때만 실행합니다. A 장소 SSID와 B 장소 IP를 섞어 허용하지 않습니다. VPN/모바일 데이터/등록 밖 Wi-Fi에서는 계좌를 조회하지 않습니다.
- 모든 등록 장소가 기존 기관별 일일 조회 기록을 공유합니다. 장소 이동, Wi-Fi 추가·수정·삭제, 마지막 항목 삭제 후 재등록으로도 그날 이미 받은 계좌를 다시 조회하지 않습니다. 계좌 키와 전송 대기 잔고도 유지합니다.
- 기존 1.10/1.11의 집 Wi-Fi는 `집 Wi-Fi` 항목 하나로 자동 이전합니다. API 키·사용자·당일 조회·전송 대기·위젯 기록을 초기화하지 않습니다. 모든 항목을 삭제하면 계좌 자동 조회를 멈추고, 하나라도 추가하면 다시 예약합니다. 삭제한 이전 항목이 재실행 때 되살아나지 않습니다.
- 조회 현황에 등록 장소 수와 최근 확인한 Wi-Fi/IP의 목록 일치 여부를 표시하고 전체 IP는 아래 등록 목록에서 확인합니다. 위치 권한과 일일 조회·위젯 반영·보안 조건은 아래와 같습니다. 아래 과거 `집 Wi-Fi` 표기는 이제 등록된 어느 장소에나 적용됩니다.

설정 최상단 `계좌 조회 현황`에서 기관별 최근 실행·동기화 성공 시각과 실제 조회 사용 IP를 확인합니다. 시각은 한국 시간이며, 실행 시각은 요청을 시작한 기록이고 성공을 의미하지 않습니다. 등록한 집 IP와 최근 확인 공인 IP를 구분하며 마지막 IP 확인 시각을 함께 표시합니다. `현재 Wi-Fi IP 확인`은 Wi-Fi 공인 IP만 확인하고 계좌를 다시 조회하지 않습니다. 네트워크 전환 후에는 버튼으로 IP를 재확인하세요.

계좌 동기화 성공 시 최신 보유정보를 다시 받아 공개 시세로 위젯 수익률을 계산합니다. 위젯 반영이 실패하거나 더 최신 자산 변경과 충돌하면 대기를 기기에 유지해 이후 작업에서 계좌 재조회 없이 재시도합니다. 재시도 간격은 최소 15분이며 Android 절전 상태에서는 늦어질 수 있습니다. 현황의 최근 위젯 반영 시각은 계좌 변경 뒤 정상 시세까지 반영된 시각입니다. 과거 버전의 실행 IP·위젯 시각은 추정해서 채우지 않습니다.

별도 클라우드 중계 서버 없이 Android 휴대폰이 키움·업비트 공식 API를 직접 호출합니다. 기존 Supabase는 로그인·보유자산 저장용으로 유지합니다. 시세 조회 방식은 Yahoo/Upbit/Frankfurter를 유지합니다.

## 처음 설정하는 순서

1. 기존 앱을 지우지 않고 최신 APK로 업데이트하고 로그인합니다. 앱을 한 번 열어 위젯용 기기 인증 등록을 완료합니다.
2. 등록할 Wi-Fi에 연결합니다. 위치 기능을 켜고 설정 → 계좌 자동 연동 → `현재 Wi-Fi 추가`를 누릅니다. 정확한 위치 권한을 허용합니다. 장소별 SSID와 Wi-Fi를 통한 공인 IPv4를 저장하며 IP 확인에는 https://api4.ipify.org 를 사용합니다. IP 확인 서비스에 API 키는 전송하지 않습니다.
3. `위치 권한 설정 열기`에서 위치 권한을 **항상 허용**, 정확한 위치 사용으로 설정합니다. Android가 백그라운드 Wi-Fi 이름을 제공하려면 필요합니다. 위치 좌표는 조회·저장하지 않습니다. VPN 사용 중이거나 SSID를 확인할 수 없으면 조회하지 않습니다.
4. 키움 https://openapi.kiwoom.com/ 에서 실전 REST API를 신청하고 국내 현금 주식·ETF 계좌의 App Key·Secret을 발급합니다. 업비트 PC 웹 Open API 관리에서 **자산조회 권한만** 선택해 Access Key·Secret을 발급합니다. 두 기관 모두 앱에 표시된 **집 공인 IPv4**를 허용 IP에 등록합니다. 집의 192.168.x.x 같은 사설 IP를 넣지 않습니다.
5. 기관별 `API 키 입력`에서 키를 입력하고 수동 자산 교체에 동의합니다. 입력은 가려서 표시하며 저장 후 입력란은 비웁니다. API 키는 Android Keystore AES-GCM으로 암호화한 앱 전용 백업 제외 파일에만 저장합니다. Supabase·GitHub·로그에 보내거나 APK에 포함하지 않습니다. 한 기관만 설정해도 됩니다.
6. 집 Wi-Fi와 공인 IP가 일치하면 첫 잔고를 조회합니다. 기관별 **최근 동기화 시각**이 표시되는지 실제 잔고와 비교합니다. `자동 조회 설정됨`은 키가 저장되었다는 의미이며 실제 연결 성공은 최근 동기화 시각으로 구분합니다.

## 하루 한 번의 의미

- 한국 시간 00:00~23:59의 날짜별, 기관별, **이 휴대폰 기준으로 정상 잔고 스냅샷을 한 번** 가져옵니다. 키움·업비트를 각각 한 번 조회하며, 키움 전체 페이지·토큰·ETF 분류 요청은 그 한 번의 조회 작업에 포함됩니다. HTTP 요청 하나만 보낸다는 의미는 아닙니다.
- WorkManager가 15분 주기의 실행 기회에 조건을 검사합니다. Android 절전 상태에서는 더 늦어질 수 있으며 연결 즉시나 정각 실행을 보장하지 않습니다. 위젯이 없어도 계좌 동기화 작업은 유지됩니다.
- 앱을 열거나 새로고침하거나 `오늘 동기화 상태 확인`을 눌러도 같은 일일 기록을 확인하므로, 그날 받은 계좌를 다시 조회하지 않습니다. 키 변경·집 Wi-Fi 재등록도 당일 기록을 초기화하지 않습니다.
- 집 SSID와 등록한 공인 IPv4가 모두 일치해야 기관 API를 호출합니다. 각 기관 HTTP 연결을 해당 Wi-Fi Network에 고정해 도중에 Wi-Fi가 끊겨도 모바일 데이터로 넘어가지 않습니다.
- 집 Wi-Fi가 없는 날은 마지막 보유정보를 유지하고 다음 가능한 날의 잔고만 가져옵니다. 누락된 과거 날짜를 몰아서 조회하지 않습니다. 집에 돌아오면 그날 아직 받지 않은 기관을 다음 작업 기회에 조회합니다.
- 기관 조회 실패는 30분 이상 뒤 재시도합니다. 전체 스냅샷 수신 후 저장만 실패하면 암호화한 잔고를 재전송하며 계좌는 다시 읽지 않습니다. 정상 수신한 잔고가 있어야 일일 조회 완료로 표시합니다. 프로세스가 응답 수신·기록 사이에 종료되는 극단적인 경우까지 외부 API의 정확히 한 번 호출을 보장할 수는 없습니다.
- 설정 화면에 최근 성공과 기관별 실패 사유를 표시합니다. 기존 자산은 실패 때문에 지우거나 0으로 바꾸지 않습니다.

## 위젯·보안·유지 관리

- 기존 자정 이후 하루 한 번 공개 시세 갱신은 유지합니다. 집에서 계좌 동기화에 성공하면 최신 보유정보와 공개 시세로 위젯도 반영합니다. 주가/코인 가격 조회와 계좌 보유수량 조회는 서로 다른 작업입니다.
- 집 공인 IP가 변경되면 자동 조회를 멈춥니다. 두 기관의 허용 IP를 수정하고 집 Wi-Fi를 다시 등록해야 합니다. 유동 IP를 자동으로 기관 허용 목록에 등록하지 않습니다.
- 로그아웃·사용자 전환 시 로컬 키·잔고 전송 대기 정보·집 Wi-Fi 설정을 삭제하고 일일 계좌 작업을 취소합니다. 다시 사용할 때는 재설정합니다. 앱 삭제·기기 교체·재설정은 기기별 일일 기록도 초기화합니다. 여러 휴대폰 사이의 계좌 API 호출 횟수는 통합하지 않습니다.
- 연결 해제는 로컬 키를 우선 삭제하고 서버의 연결 자산을 수동 자산으로 전환합니다. 오프라인 등으로 서버 해제가 실패하면 앱의 오류를 확인하고 인터넷 연결 후 다시 시도합니다.
- 기기 인증 토큰은 1년 유효하며 앱을 열 때 등록을 갱신합니다. 새 인증 등록에서만 잔고 제출 권한을 부여하고 기존 1.9 위젯 토큰은 기본 조회 권한만 유지합니다. Supabase 기본 JWT 검증과 기기 토큰 해시·만료일·소유권 검증을 모두 유지합니다. 관리 키·기관 API 비밀키는 서버로 보내지 않습니다.
- 키움 토큰은 일일 조회 시 발급하고 업비트 요청 JWT는 매번 생성합니다. 기관 API 키 자체 만료·폐기는 자동 연장하지 않습니다. Android 강제 종료·위치/백그라운드 권한 차단·인터넷 문제로 작업이 지연/중단될 수 있습니다.

## 지원 범위와 검증 한계

키움 한 계좌의 국내 현금 주식·ETF, 업비트 한 포켓의 KRW 기준 코인(balance+locked)을 지원합니다. 미래에셋·해외주식 계좌·예수금·신용·대주·ETN/ELW는 지원하지 않습니다. 정상 전체 잔고만 원자적으로 반영하며 최초 동의 시 해당 기관의 지원 대상 수동 자산을 교체합니다. 전체 자산 최대 49개입니다. 원금 0 코인은 평가금액·손익을 표시하고 수익률은 —로 표시합니다.

모의 응답 기반 단위 테스트, DB 권한/트랜잭션 검사 및 APK 빌드로 확인합니다. 실제 키는 아직 준비되지 않았으므로 실계좌 응답·집 공유기 IP·휴대폰 위치 권한·밤사이 동작·배터리는 설정 후 실기기 확인이 필요합니다.

이전 1.9 고정 IP 중계 서버 구성은 [과거 안내](ACCOUNT_CONNECTIONS_GATEWAY_LEGACY.md)에 보존합니다. 최신 앱의 계좌 동기화는 해당 중계 서버를 호출하지 않습니다. 기존 버전 호환을 위한 서버 코드는 보존합니다.
