# 보유자산 홈 화면 위젯 · 1.4.0

총평가금액 아래와 평가손익·수익률 아래에 1dp 가로 구분선을 표시합니다. 각 선의 위아래에는 12dp 여백을 둡니다.

전체 평가손익 금액은 왼쪽, 전체 수익률은 오른쪽 끝에 표시합니다. 두 값 사이에 최소 20dp 간격을 두며 항목명도 각각 위에 정렬합니다.

1. APK를 기존 앱 위에 설치하고 로그인 후 자산을 조회합니다.
2. 앱 설정 → 보유자산 위젯 → 홈 화면에 위젯 추가를 누르고 휴대폰에서 추가를 확인합니다. 지원하지 않는 런처에서는 홈 화면 빈 공간 길게 누르기 → 위젯 → 통합 자산관리 → 보유자산을 선택합니다.
3. 위젯을 길게 눌러 크기를 조절하고 보유종목 목록을 위아래로 스크롤합니다.

표시: 총평가금액, 전체 평가손익(원화)·수익률(%), 종목명·종목 수익률(%). 제목·금융기관명·갱신 안내 문구는 표시하지 않습니다. 총투자원금, 종목별 평가금액·손익 금액도 표시하지 않습니다. 전체 수익률은 총 원금을 기준으로 계산합니다. 종목은 평가금액 내림차순이며 시세가 없으면 —로 표시합니다. 총평가금액은 30sp, 평가손익·수익률은 20sp, 종목명은 16sp, 종목 수익률은 18sp입니다.

위젯은 앱이 최근에 조회·반영한 데이터를 보관합니다. 앱에서 자산이나 시세를 갱신하면 함께 갱신되고 위젯을 누르면 앱을 열어 조회합니다. 앱이 닫힌 동안 별도 서버 조회나 실시간 갱신은 수행하지 않습니다. 반영 시각과 시세 상태 안내는 앱에서 확인합니다. ETF·환율의 기준 데이터 주기는 기존 앱과 같습니다.

로그아웃·계정 변경 시 이전 계정 데이터는 지웁니다. 위젯 저장본에는 API 키나 인증 토큰을 넣지 않으며 앱 전용 백업 제외 영역에 저장합니다.

Android 7 이상에서 사용하며 기본 4×4, 가로·세로 크기 조절을 지원합니다. 설정의 추가 버튼은 Android 8 이상 및 해당 런처의 지원 여부에 따르며 수동 추가도 가능합니다. 실제 배치 크기와 목록 스크롤은 런처에 따라 달라질 수 있습니다.
